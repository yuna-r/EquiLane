Intel Intrinsics 移植検証

検証状態: 未適合・検証指摘あり

Intel Intrinsics の動作を各アーキテクチャへ正しく移植できているか、Intel の実行結果を基準としてケース契約に沿って検証します。Guide の関数をケースへ対応付け、共通入力を各実装の C ABI に渡し、戻り値とメモリ出力を照合します。

共通環境は Ubuntu 26.04 LTS。対象は Intel / SSE2（linux/amd64）、OpenPOWER / VSX（linux/ppc64le）、ARM64 / NEON（linux/arm64）、RISC-V64 / RVV（linux/riscv64）。異種 CPU の実行はエミュレータの観測として扱います。

実行・テスト工程の成否と、出力の意味上の一致を分けて表示します。各対象の詳細には _mm_* 関数、シグネチャ、操作、アーキテクチャ間の対応、期待値と実測値をまとめます。

ケース契約で許容されない不一致は移植の不適合として扱い、原因の調査が必要です。契約が明示的に許容する差は比較ルールに従います。補助的な wrapper のビット差だけから個別の不具合を断定せず、契約に基づく判定と入力・実測値を確認してください。
